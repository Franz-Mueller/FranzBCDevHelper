# Franz BC Dev Helper

The Franz BC Dev Helper is a work in progress project that aims to make Business Central development easier. By managing docker containers, repositories, dependencies, and more, the Dev Helper removes much of the usual overhead. Software developers can focus on architecture and coding while non technical vibe coders might as well skip the steps of learning about docker and git basics by directly hooking the dev helper up to their favorite agent via mcp. 

As of now there is no usable version. The goal is to release the first useful version before 2027 and the "final" version before Oct 2027.
